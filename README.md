# Noodle Fun Finance（财务结算软件 / Buchhaltung）

Windows 桌面软件：记录每日营业额（现金、刷卡、Lieferando、foodora、wolt，毛额）和支出，
月度汇总，导出日报/月报 PDF，界面中文/德语切换，支持从 GitHub 自动检测并安装更新。

## 首次上传 GitHub
1. 新建 **public** 仓库，例如 `noodlefun-finance`，把本文件夹全部内容推送上去。
2. `nffinance/version.py` 里的 `GITHUB_REPO` 已设为 `codex112026/noodlefun-finance`。
3. 发布第一个版本：
   ```
   git tag v1.0.0
   git push origin v1.0.0
   ```
   GitHub Actions 会自动打包，并在 Releases 页面生成 `NoodleFunFinance-Setup.exe`。
4. 在 Windows 上下载安装 Setup.exe 即可使用（安装到当前用户目录，不需要管理员权限）。

## 发布更新
改完代码提交后，打一个更高版本号的 tag（如 `v1.0.1`）并推送。已安装的软件在启动时会
自动检测到新版本，提示后下载并静默安装，完成后自动重启。也可在「帮助 → 检查更新」手动检查。

## 数据
- 数据文件夹：首次运行时自行选择（建议放在 OneDrive）；数据库 `finance.db` 同时保存语言等设置。重装后启动软件，选回原文件夹即可恢复。菜单「文件 → 更改数据文件夹」可随时切换。
- 「文件 → 备份数据库」可导出备份文件。

## 本地运行（开发）
```
pip install -r requirements.txt
python run.py --no-update-check
```

## 键盘操作
- 日期框：↑↓ 增减日，←→ 增减月；Enter 跳到下一项。
- 金额框默认留空，输入 `12,5` 或 `12.50` 均可；在最后一项按 Enter 会询问是否保存/添加。
- 已保存的表格：双击任意单元格（含日期）即可修改，改日期后数据跟着新日期走。

## 工资结算
- 「工资结算」页签：先在「工人管理」里建档（姓名、时薪、封顶月薪，或填月薪后点“按月薪计算时薪”）。
- 时薪两种自动算法：
  - 粗算：月薪 ÷ (30 − 休息日) ÷ 每日工作小时
  - 奥地利会计：月薪 ÷ (4,33 周 × 每周小时)，每周 40 小时即 173,2 小时/月
  时薪四舍五入到分，算出后仍可手动改。
- 每日录入上班/下班时间和休息分钟（下班早于上班按跨午夜计算），工时自动算出。
- 月工资 = min(总工时 × 时薪, 封顶月薪) + 加班费；封顶月薪留空表示不封顶，加班费手动输入、不受封顶限制。
- 「导出工资单 PDF」：全部工人（首页汇总 + 每人一页）或仅当前工人。

### 工资结算（补充）
- **结算方式**（每个工人每月可单独选）：按每日工时，或「直接输入本月总工时」（此时每日记录不计入）。
- **加班时间**（小时，另计，不含在总工时内）= 加班小时 × 时薪 × 加班倍率（倍率在工人档案里设置，默认 1,5）；
  另可输入「另加加班费」金额。加班费都不受封顶限制。
- **应付** = 基本工资（封顶后）+ 加班费；**实付** = 转账金额 + 现金金额；
  **累计应付** = 上月结转未付 + 本月应付 − 本月实付。
- **在职/离职**：离职工人仍可查看以前月份；有未付结转时继续出现在汇总里。
- **汇总与报表**：工资支出并入总支出与结余，可选「按应付」或「按实付」计入；月报 PDF 增加「工资支出」明细。
- 注意：工人时薪、封顶、倍率是当前值，修改后所有月份会按新值重算。
